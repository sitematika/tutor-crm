# A-teacher CRM

CRM для репетитора английского языка. Отдельный сайт на React + Vite с компонентами [React Bits](https://reactbits.dev).

## Возможности

- **Ученики** — профили с уровнем CEFR, контактами, заметками и закладкой «где остановились» (учебник/страница)
- **Галочка «оплачено»** рядом с именем — для тех, кто платит поурочно
- **Счёт в гривнах (₴)** — для тех, кто платит наперёд: оплаты пополняют счёт, проведённые уроки списывают ставку
- **Расписание недели** — общая сетка всех учеников, добавление нового урока в пару кликов
- **Оплаты** — сводка и таблица статусов (оплачено / ждёт оплаты / долг)
- Светлая и тёмная тема (переключатель + системная по умолчанию), шрифт Manrope
- Данные хранятся в localStorage браузера

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

## Использованные компоненты React Bits

- `SpotlightCard` — карточки учеников
- `CountUp` — анимированная статистика на вкладке «Оплаты»
- `FadeContent` — появление разделов
